# Code of Conduct

William's AI Studio uses the Contributor Covenant Code of Conduct, version 2.1, as the baseline community standard.

## Our Pledge

We pledge to make participation in this project a respectful and harassment-free experience for everyone, regardless of background, identity, experience level, or technical specialization.

## Expected Behavior

Examples of behavior that contributes to a productive community include:

- treating others with respect;
- giving actionable technical feedback;
- accepting responsibility for mistakes;
- focusing criticism on code, documentation, design, and process rather than people;
- respecting privacy and security boundaries.

## Unacceptable Behavior

Unacceptable behavior includes:

- harassment, intimidation, or discrimination;
- insults, personal attacks, or sustained disruption;
- publishing private information without permission;
- posting secrets, tokens, private logs, or vulnerable private endpoints;
- knowingly submitting copyrighted, private, or unsafe data without disclosure.

## Enforcement

Project maintainers may remove content, reject contributions, limit participation, or take other reasonable action when behavior violates this code of conduct.

Security-sensitive reports should follow `SECURITY.md` rather than public discussion.
